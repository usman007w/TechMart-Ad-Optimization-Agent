# \# TechMart Ad Optimization Agent 

# 

# AI-powered system that analyzes sales and ad data to automatically recommend which ads to boost, maintain, or discard.

# 

# \## Project Overview

# \- \*\*185,686 sales records\*\* analyzed

# \- \*\*1,143 ad campaign records\*\* analyzed

# \- \*\*19 products\*\* evaluated

# \- \*\*4 ML models\*\* trained and compared

# 

# \## Key Results

# \- Decision Tree Regressor: R² = 0.894 (explains 89.4% revenue variance)

# \- Decision Tree Classifier: Accuracy = 63%

# \- Successfully predicts revenue and conversions

# 

# \## Technologies Used

# \- Python, Pandas, NumPy

# \- Scikit-learn (ML models)

# \- Matplotlib, Seaborn (visualizations)

# \- Streamlit (web app)

# 

# \## How to Run

# 

# \### 1. Install Dependencies

# ```bash

# pip install pandas numpy scikit-learn matplotlib seaborn streamlit

# ```

# 

# \### 2. Run Streamlit App

# ```bash

# streamlit run App.py

# ```
